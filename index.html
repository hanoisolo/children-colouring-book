My Colouring Book

A personalised colouring book, drawn from a theme and a name.

This app has to be served over HTTP. Opening index.html straight from disk blocks ES modules, so nothing will generate. Run npm start and open http://localhost:8000, or use the single-file build in dist/colouring-book.html, which needs no server.

Try “space dinosaurs”, “under the sea”, or “fairy garden”.

Letters, spaces, hyphens and apostrophes. Up to 20 characters.

With a key, the six pages are drawn by Gemini’s cheapest image model. Without one, the book is drawn offline as vector art. The key stays in this tab and is sent only to generativelanguage.googleapis.com.
